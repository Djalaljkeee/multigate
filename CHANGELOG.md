версии — по [семантическому версионированию](https://semver.org/lang/ru/).

### Добавлено
- Шапка README с баннером, бейджами и ссылками на сообщество.
- `CONTRIBUTING.md`, `SECURITY.md`, шаблоны задач и pull request.

## [0.1.0] — не выпущено

Первая версия прослойки. Релиз появится после первого тега `v*`:
до этого момента образ в GHCR не публикуется.

### Добавлено
- Два режима работы: зеркало подписки и самостоятельная выдача через API панели.
- Определение приложения, версии, ядра и устройства по User-Agent.
- Журнал запросов с фильтрами по пользователю, устройству, адресу, приложению и решению.
- Локальные блокировки пользователя и отдельного устройства.
- Правила ответа под конкретные приложения: имя профиля, ссылка поддержки, интервал обновления.
- Грейс для истёкших подписок: временный сквад со снимком исходного состояния.
- Пул конфигов WireGuard и AmneziaWG с привязкой к устройству.
- Страница-маскировка для браузерных заходов.
- Ретрансляция вебхуков панели на несколько адресов, каждому своя подпись.
- Чат поддержки с пересылкой в Telegram и своим зеркалом Bot API.
- Админка со всем перечисленным, встроенная в бинарник.
- Установщик `install.sh` с обновлением и откатом, юнит systemd, образ Docker.
